# The three languages share one reference, with no per-language guides

Lua, JavaScript and TypeScript are presented as equals: every example is tabbed in that order, and what is specific to a language (its standard library, its sandbox, TypeScript's compilation) lives in one Languages reference page. There is no "Lua scripting" guide, because a guide per language would repeat the script contract three times and let the languages drift apart in the docs while they don't in HappyView. The old Lua guide's URL redirects to the Languages reference.
