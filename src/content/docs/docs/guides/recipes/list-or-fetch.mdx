This query handles both single-record lookups (when a `uri` param is provided) and paginated listing.

**Trigger:** `xrpc.query:<nsid>`. **Needs:** `happyview-db`.

<Tabs syncKey="lang">
<TabItem label="Lua">

```lua
local db = require("happyview.db")

function handle(input, ctx)
  if input.uri then
    local row = db.get(input.uri)
    if not row then
      return { error = "RecordNotFound", message = "no record at that uri" }
    end
    return { record = row }
  end

  return db.records("xyz.statusphere.record")
    :did(input.did)
    :limit(tonumber(input.limit) or 20)
    :cursor(input.cursor)
    :run()
end
```

## How it works

1. If a `uri` query parameter is provided, fetch that single record with `db.get` and return it. If it doesn't exist, return a `RecordNotFound` error; raising one would answer 500. The response is a 400 only when the lexicon declares `RecordNotFound` under `defs.main.errors`, as in `"errors": [{ "name": "RecordNotFound" }]`. Otherwise it is a 200.
2. Otherwise, list records from the `xyz.statusphere.record` collection with a `db.records` chain, with optional filtering by `did` and cursor-based pagination. The `cursor` is an opaque string from a previous response, so pass it through directly. A `limit` the lexicon declares as an `integer` arrives as a number already. The script converts it for a lexicon that leaves `limit` untyped, where it arrives as a string.

## Usage

```
GET /xrpc/xyz.statusphere.listRecords?limit=10
GET /xrpc/xyz.statusphere.listRecords?did=did:plc:abc
GET /xrpc/xyz.statusphere.listRecords?uri=at://did:plc:abc/xyz.statusphere.record/abc123
```
