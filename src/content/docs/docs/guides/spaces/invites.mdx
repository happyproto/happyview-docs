:::danger[Experimental]
This API is experimental and will change. See the [atproto spaces overview](/docs/guides/spaces) for context.

Invites let space creators distribute invite tokens without knowing recipients' DIDs in advance.

:::note[HappyView extension]
Invites are a HappyView-specific feature, not part of the atproto spaces spec.
:::

## Creating an invite

Only the space's creator or an operator with superadmin can create invites.

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
const response = await fetch("https://happyview.example.com/xrpc/dev.happyview.space.createInvite", {
  method: "POST",
  headers: {
    "X-Client-Key": CLIENT_KEY,
    "Authorization": `DPoP ${ACCESS_TOKEN}`,
    "DPoP": DPOP_PROOF,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    space: "at://did:web:happyview.example.com/space/com.example.forum/main",
    access: { read: true, write: true },
    maxUses: 10,
    expiresAt: "2026-06-01T00:00:00Z",
  }),
});
interface CreateInviteResponse {
  inviteId: string;
  token: string;
  access: { read: boolean; write: boolean };
  maxUses: number | null;
  expiresAt: string | null;
}
const data: CreateInviteResponse = await response.json();
```


<TabItem label="cURL">

```sh

  -H 'X-Client-Key: hvc_...' \
  -H 'Authorization: DPoP <token>' \
  -H 'DPoP: <proof>' \
  -H 'Content-Type: application/json' \
  -d '{
    "space": "at://did:web:happyview.example.com/space/com.example.forum/main",
    "access": { "read": true, "write": true },
    "maxUses": 10,
    "expiresAt": "2026-06-01T00:00:00Z"
  }'
```

</TabItem>
</Tabs>

**Input:**

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `space` | string | Yes | | The space this invite is for |
| `access` | object | No | `{ "read": true, "write": false }` | Access granted on acceptance: `read` and `write` booleans, both required when `access` is given |
| `maxUses` | integer | No | unlimited | Maximum number of times the invite can be redeemed |
| `expiresAt` | string (datetime) | No | never | When the invite expires, in UTC (ending in `Z` or `+00:00`) |

**Response (201):**

```json
{
  "inviteId": "uuid",
  "token": "a1b2c3d4e5f6...",
  "access": { "read": true, "write": true },
  "maxUses": 10,
  "expiresAt": "2026-06-01T00:00:00Z"
}
```

:::caution
The `token` is only returned once. It is stored as a SHA-256 hash, so HappyView cannot recover the plaintext.
:::

## Accepting an invite

Any authenticated user can accept an invite token to join the space.

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
const response = await fetch("https://happyview.example.com/xrpc/dev.happyview.space.acceptInvite", {
  method: "POST",
  headers: {
    "X-Client-Key": CLIENT_KEY,
    "Authorization": `DPoP ${ACCESS_TOKEN}`,
    "DPoP": DPOP_PROOF,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    token: "a1b2c3d4e5f6...",
  }),
});
interface AcceptInviteResponse {
  uri: string;
  access: { read: boolean; write: boolean };
}
const data: AcceptInviteResponse = await response.json();
```

```json
{

  "access": { "read": true, "write": true }
}
```

Acceptance fails if:

- The token is invalid (no matching hash found): `404`
- The invite has been revoked: `400`
- The invite has reached its `maxUses`: `400`
- The invite has expired: `400`
- The user is already a member of the space: `409`

Only the space's creator or an operator with superadmin can revoke an invite. Revoking prevents future redemptions but does not remove members who already redeemed it. A revoke answers `{"success": true}`, and an `inviteId` that is not one of the space's invites fails with `404`.

## Listing invites

Only the space's creator or an operator with superadmin can list invites.

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
const response = await fetch(
  "https://happyview.example.com/xrpc/dev.happyview.space.listInvites?space=at://did:web:happyview.example.com/space/com.example.forum/main",
  {
    headers: {
      "X-Client-Key": CLIENT_KEY,
      "Authorization": `DPoP ${ACCESS_TOKEN}`,
      "DPoP": DPOP_PROOF,
    },
  },
);
interface Invite {
  id: string;
  access: { read: boolean; write: boolean };
  maxUses: number | null;
  uses: number;
  expiresAt: string | null;
  revoked: boolean;
  createdBy: string;
  createdAt: string;
}
const data: { invites: Invite[] } = await response.json();
```


List responses carry the invite metadata and never the token.
