:::caution[This page is being written]
It will cover `hpy happyview dev`: the local instance it runs at `http://127.0.0.1:3000`, the dashboard it prints a link to, reloading on save, and `--network local` for working without touching the real network. One thing to know before you run it: by default a local instance writes to your real atproto account's PDS, so sign in with a separate test account.
:::
