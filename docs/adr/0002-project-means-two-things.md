# "Project" means one thing on each side, and the docs qualify the HappyProto one

On HappyView's side a project is the directory with `happyview.toml` and `src/` that is deployed to an instance. In the HappyProto dashboard a project is a container that holds one HappyView instance today and will hold other services (a PDS, a labeler, a relay) later. Both names are established in their products, so neither is renamed. How the docs tell them apart is open (docs grilling round 2): the proposal is "project" for the directory and "HappyProto project" for the container, wherever the HappyProto dashboard comes up.
