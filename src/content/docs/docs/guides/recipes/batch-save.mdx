Create several records from one request.

**Trigger:** `xrpc.procedure:<nsid>`. **Needs:** `happyview-record`.

<Tabs syncKey="lang">
<TabItem label="Lua">

```lua
local json = require("internal.json")
local record = require("happyview.record")

function handle(input, ctx)
  local uris = {}
  for _, item in ipairs(input.items) do
    local ref = record.create("com.example.post", item)
    uris[#uris + 1] = ref.uri
  end
  return { uris = json.to_array(uris) }
end
```

## How it works

1. Iterate over `input.items` and create each one with `record.create` on [`happyview.record`](/docs/reference/scripts/libraries).
2. Collect the resulting AT URIs and return them. In Lua, `json.to_array` keeps `uris` a JSON array when `items` is empty.

Writes happen one at a time, in order. If one fails, the records before it exist and the ones after it don't, and the app gets an error response: a 500, or a 401 when the caller's PDS session has ended. To report partial progress instead, wrap `record.create` in `pcall` (Lua) or `try`/`catch` (JavaScript and TypeScript).

## Usage

The DPoP proof is signed per request; an app built on the [HappyView SDK](/docs/reference/sdk) gets this from its session.

## Use case

Use a batch save when a single user action should create several records, such as importing data or finishing a multi-step form.
