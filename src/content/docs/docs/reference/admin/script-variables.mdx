## List script variables

```
GET /admin/script-variables
```

Requires `script-variables:read`. Returns the variables ordered by key. Values are never returned, only a masked `preview`: the value's first four characters followed by `****`, or only asterisks for a value of four characters or fewer.

**Response**: `200 OK`

```json
[
  {
    "key": "API_TOKEN",
    "preview": "sk_l****",
    "created_at": "2026-03-01T00:00:00Z",
    "updated_at": "2026-03-01T00:00:00Z"
  }
]
```

## Upsert a script variable

```
POST /admin/script-variables
```

Requires `script-variables:create`. Sets `value` for `key`, creating the variable or replacing its value. Both fields are required strings.

**Response**: `204 No Content`

## Delete a script variable

```
DELETE /admin/script-variables/{key}
```

Requires `script-variables:delete`.

**Response**: `204 No Content`. Returns `404 Not Found` for an unknown key.
