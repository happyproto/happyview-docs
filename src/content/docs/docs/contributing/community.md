HappyView's bug reports, feature requests and contributions go through its GitHub repository, [gamesgamesgamesgamesgames/happyview](https://github.com/gamesgamesgamesgamesgames/happyview).

## Report a problem or ask for a feature

Open an issue in the [issue tracker](https://github.com/gamesgamesgamesgamesgames/happyview/issues). The repository has no issue templates, so include:

- the HappyView version you run, as shown on the GitHub release you installed or in the container image tag;
- the database backend, SQLite or Postgres;
- what you did, what you expected, and what happened, with the exact error text or log lines.

Check [Troubleshooting](/docs/guides/troubleshooting) first, since it covers common errors and their fixes.

Report a security vulnerability through the [Security policy](/docs/contributing/security), not the issue tracker.

## Contribute a change

See [Develop](/docs/contributing/develop) for how to set up a checkout and what a pull request needs, and [Test](/docs/contributing/test) for running the checks.

## Code of conduct

Participation in the project is covered by its [Code of Conduct](https://github.com/gamesgamesgamesgamesgames/happyview/blob/alpha/CODE_OF_CONDUCT.md), which is the Contributor Covenant 3.0. To report a possible violation, email [harassment@birb.house](mailto:harassment@birb.house). The Code of Conduct describes how reports are investigated and the enforcement steps that can follow.
