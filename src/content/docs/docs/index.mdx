HappyView is an open source, batteries-included AppView for building projects on [atproto](https://atproto.com). It indexes records from the network and serves an XRPC API over them. Lexicons define the records to be indexed, as well as the XRPC endpoints to be served. Scripts define the functionality of each endpoint, as well as what happens when a record changes.

HappyView also provides an authentication layer, simplifying atproto OAuth and allowing writes to users' PDSes.

These are the docs for HappyView v3 (in beta). If you're still on v2, use the [HappyView v2 docs](https://v2.happyview.dev).
