# Example tabs follow who runs the code

Script examples are tabbed Lua, JavaScript, TypeScript, as [ADR 6](0006-languages-share-one-reference.md) decided, because those are the languages a script can be written in. Examples of an app calling HappyView are tabbed TypeScript, JavaScript, Rust, Go, cURL, because an app can be written in anything that speaks HTTP. ADR 6 said "every example", which read literally would put Lua in a client example that can never run it.

One tab order everywhere was the alternative. It reads as more consistent and would suggest languages that don't apply on one side or the other.
