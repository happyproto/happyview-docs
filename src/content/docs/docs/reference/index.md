These pages give the exact shape of HappyView's commands, configuration, script API and HTTP APIs:

- [CLI](/docs/reference/cli): the `happyview` and `hpy` commands.
- [Configuration](/docs/reference/configuration): `happyview.toml` and environment variables.
- [Script API](/docs/reference/scripts/contract): the `handle(input, ctx)` contract, triggers, languages, limits and libraries.
- [XRPC API](/docs/reference/xrpc): the endpoints every instance serves, and the ones your lexicons add.
- [Admin API](/docs/reference/admin/admin-api): managing an instance over HTTP.
- [Authentication](/docs/reference/authentication): how apps, users and operators authenticate, and the `/oauth` endpoints.
- [Third-party API clients](/docs/reference/oauth): the methods apps manage their own API clients with, and client assertions.
- [Lexicons](/docs/reference/lexicons): how each lexicon type behaves, and how network lexicons and unknown methods resolve.
- [Plugin SDK](/docs/reference/plugin-sdk): writing WebAssembly plugins.
- [JavaScript SDKs](/docs/reference/sdk): client libraries for apps that talk to HappyView.
