## Record counts

```
GET /admin/stats
```

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
interface CollectionCount {
  collection: string;
  count: number;
}

interface Stats {
  total_records: number;
  collections: CollectionCount[];
}

const response = await fetch("http://127.0.0.1:3000/admin/stats", {
  headers,
});
const data: Stats = await response.json();
```

</TabItem>
<TabItem label="JavaScript">

```js
const response = await fetch("http://127.0.0.1:3000/admin/stats", {
  headers,
});
const data = await response.json();
```

</TabItem>
<TabItem label="Rust">

```rust
let client = reqwest::Client::new();
let response = client
    .get("http://127.0.0.1:3000/admin/stats")
    .bearer_auth(token)
    .send()
    .await?;
let data: serde_json::Value = response.json().await?;
```

</TabItem>
<TabItem label="Go">

```go
req, _ := http.NewRequest("GET", "http://127.0.0.1:3000/admin/stats", nil)
req.Header.Set("Authorization", "Bearer "+token)
resp, err := http.DefaultClient.Do(req)
```

</TabItem>
<TabItem label="cURL">

```sh
curl http://127.0.0.1:3000/admin/stats -H "$AUTH"
```

</TabItem>
</Tabs>

**Response**: `200 OK`

```json
{
  "total_records": 12345,
  "collections": [{ "collection": "xyz.statusphere.status", "count": 500 }]
}
```

## Admin and client counts

```
GET /admin/stats/counts
```

Returns the number of operators (seats, including those with superadmin) and registered API clients. It is cheap to call often, unlike the record counts above. Requires `stats:read`.

<Tabs syncKey="lang">
<TabItem label="cURL">

```sh
curl http://127.0.0.1:3000/admin/stats/counts -H "$AUTH"
```

</TabItem>
</Tabs>

**Response**: `200 OK`

```json
{
  "users": 3,
  "api_clients": 2
}
```
